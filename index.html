DailyPlate Culinary Universe

This web application is built with React & Vite. Modern web browsers block JavaScript modules from loading directly through file:/// links due to security (CORS) rules.

⚡ To start the application:
1. Open your terminal in this project folder:
cd "c:\Users\User\Downloads\chamz bubs"
2. Start the local development server:
npm run dev
3. Open in your browser:
http://localhost:5173

Once the server is started and opened via localhost, the full interactive app with AI Coach, Kitchen, and recipes will load immediately.
